# About the BS.ch Digital Design System

Welcome to the Digital Design System documentation of BS.ch. This documentation aims to explain how to use the DDS ("Digital Design System"), inform about its purpose and goals and illustrate various concepts behind it.

## Purpose and goals

The purpose of the DDS ("Digital Design System") is to provide a unified and low-threshold way to build websites with the look and feel of www.bs.ch.

The system itself consists of three pillars:
 * The Figma file: It contain the overall design specifications, reasoning and the nitty-gritty details.
 * The Unplugin: The software used to install all the CSS necessary to create the look & feel.
 * The Storybook: The thing you're currently looking at.

The individual pillars are discussed in their respective chapters and found in the navigation.

## Usage

To create a website using the DDS, follow these steps:

 1. Create your application with a framework of choice. The only hard dependency is a frontend build tool, such as Vite, Webpack, ESBuild or similar.
 2. Install the DDS Unplugin as a dependency and configure it according to its documentation.
 3. Start building your application backend and frontend.
 4. Build frontend components with markup found in Storybook

It is essential that you keep the DDS Unplugin up to date. The maintainers will inform you of any significant updates.

To get started using Storybook, Tailwind (and to some extent bs.ch), please refer to section **3. Usage Tutorials**. To install
the DDS, please refer to the guide on [2.2.1. How to install and configure the DDS Unplugin](/docs/2-tutorials-2-usage-tutorials-1-how-to-install-and-configure-the-dds-unplugin--docs).

## How to get started with learning the DDS

The documentation of the DDS and its parts is described in two chapters named "Contribution Tutorials" and "Usage Tutorials".

Depending on your knowledge about the frameworks used, you might want to start with official documentations first.

### I want to contribute to the DDS

 * Official documentations:
   * [Tailwind](https://v3.tailwindcss.com)
   * [Unplugin](https://unplugin.unjs.io)
   * [Storybook](https://storybook.js.org)
   * [Vite](https://vite.dev/)
   * [Lit](https://lit.dev)
   * [React](https://react.dev)
 * In case you want to contribute, i.e. provide bugfixes, implement new components, or do maintenance, please start with the README files of both Storybook and the Unplugin. They offer exhaustive guides on how to get everything up & running, how to run tests, etc.

### I want to use the DDS

In case you want to use the DDS, if you're unfamiliar with Tailwind, start by reading the
[official Tailwind documentation](https://v3.tailwindcss.com). Once done, you can continue with setting up the Unplugin
in your project. To do that, head to the first Usage tutorial
[2.2.1. How to install and configure the DDS Unplugin](/docs/2-tutorials-2-usage-tutorials-1-how-to-install-and-configure-the-dds-unplugin--docs).

Once everything is up and running in your project, you may want to continue learning about either the Figma file, Tailwind,
or how to use the Unplugin and Storybook to write your first DDS-based page. For this, please consult
[2.2.4. How to use Storybook to build a page](/docs/2-tutorials-2-usage-tutorials-4-how-to-use-storybook-to-build-a-page--docs).
