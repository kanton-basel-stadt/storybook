# 2.11. How to use the DDS with Prettier

To get linting up&running for the **prettier-plugin-tailwindcss**, you need to follow these steps:

 * Install prettier-plugin-tailwindcss: `npm i -D prettier prettier-plugin-tailwindcss`
 * Add the following code your `.prettierrc` file:
   ```
   "plugins": ["prettier-plugin-tailwindcss"],
   "tailwindStylesheet": "./node_modules/@kanton-basel-stadt/designsystem/dist/assets/css/tailwind.css",
   "tailwindConfig": "./node_modules/@kanton-basel-stadt/designsystem/dist/configs/tailwind.config.ts"
   ```
