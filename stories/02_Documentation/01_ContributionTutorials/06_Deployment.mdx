# 2.1.6. Deployment

## Unplugin

To deploy a new version, commit and push your changes. Once you're adapting the Unplugin, make sure the build passes (linting + test execution)
and verify that it builds by executing `npm run build`.

In order to release a new version, you need to be a member of the NpmJS organization. You can then execute
`npm run release` and follow the on-screen instructions.

Please be aware, that a new Git tag will be created. It will be pushed and a browser window with Github will open where
you can add a changelog, describe what the new version does, etc. Once that's done, you can return to your terminal and
follow the rest of the on-screen instructions.

Once a new version is release, don't forget to inform all necessary people and update the version of the Unplugin within
Storybook as well.

Since the Unplugin is technically not hosted anywhere, no further actions are necessary.

## Storybook

To deploy a new version of Storybook, a new commit is necessary. Every push to the `main` branch constitutes a new
deployment to Github pages. No further action is necessary, other than testing that it was successful by accessing it.
