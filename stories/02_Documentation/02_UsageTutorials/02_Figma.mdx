# 2.2.2. About the Figma file

This Figma file are the single source of truth regarding design and design concepts. They should be consulted in case
of any confusion about the design.

## How to work with Figma

The way Figma works is component based. Generally speaking, a Figma design is itself a component that consists of
several more components. These components are described in the Design system Figma file, in which you will find further
components. These components are implemented in Storybook and should have a link in Figma to Storybook.

To find out how to use the Storybook components, please refer to the page [**"How to use Storybook to build a page"**](/docs/2-tutorials-2-usage-tutorials-4-how-to-use-storybook-to-build-a-page--docs) of the tutorials.

In case components are missing or aren't linked, please refer to the page [**"How to use Tailwind"**](/docs/2-tutorials-2-usage-tutorials-3-how-to-use-tailwind--docs) or [**"How to use BS.ch to find missing components"**](/docs/2-tutorials-2-usage-tutorials-5-how-to-use-bs-ch-to-find-missing-components--docs) of the tutorials.
