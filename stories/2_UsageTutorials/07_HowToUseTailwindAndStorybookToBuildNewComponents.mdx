# 3.8. How to use use Tailwind and Storybook to create new components

Storybook and Tailwind go hand in hand. Tailwind styles all components within Storybook and can be used to cerate components
not present in Storybook, while Storybook provides a lot of marup necessary to build full-fledged pages. **Storybook
components are like LEGO® bricks: They provide a general structure and can be combined to create larger structures.**

However, unlike LEGO® bricks, the DDS offers tools to glue the bricks together in whichever way necessary and to create
your own bricks! This tool is Tailwind and good old HTML.

In this tutorial, we learn how to combine Storybook components with our own HTML and Tailwind's utility classes.

## Step One: Gather sub-components

Suppose we would like to create a **search page**. The first thing we need to do, is to gather all necessary components.

Our first station for that is **Figma**. On the search page, we see that we have several different building blocks:

 * The search header
 * The search results
 * The pagination
 * The "More results elsewhere" box
 * And, sometimes, the "No results" section

We can find these within Storybook, when we look at the "Search" folder, located within "Components for web".

We might also need a page frame. For that, we need:

 * The page header
 * Breadcrumbs
 * The page footer

## Step Three: Add non-component structure

We notice that the search results span the entire page. However, on bs.ch, we see that the search results only cover
part of the width. How do we reproduce this behaviour?

From our experience with Tailwind, we know that we need a **container**. The simplest container that is also responsive,
is a div with the `container` class. To center the container, we can use the class `mx-auto`, which means "margin on the
x axis: auto", which centers the component.

Our code now looks like this:

```html

<html>
  <head>
    <!-- Include CSS here according to your framework -->
  </head>

    >

          <h1 class="sr-only">Hauptnavigation</h1>
          <!-- More HTML here... -->

    </div>

    <!-- BREADCRUMBS -->

      class="bg-gray-20 border-b border-b-gray-400 -mt-1 relative print:hidden"

      aria-label="Breadcrumb"

      <div class="container relative">
```

We can do these for all kinds of components! We can add more HTML and CSS as we see fit, even adjust classes of existing
components in our project and rebuild all of BS.ch, down to the last details.

## Step Four: Add logic

This step is highly dependant on your framework of choice. If you're using Vanilla JS, you may create a `search.js` file
and control the class lists and visibility of search components, fetch search results and show loading states.

## Conclusion

In this tutorial, we have learned that Storybook components behave like LEGO® bricks and that Tailwind can be used to glue
components together, change their look and to create new components that we haven't yet developed or that are new and
special to our project.
