# 2.2.4. How to use Storybook to build a page

Storybook provides a set of default components, such as form inputs, form elements (stepper navigation, fieldsets, etc.),
the page header and footer, tables, typography and much more.

## Overview

In this tutorial, you'll learn how to use the components available in Storybook to build a page. You'll be able to
customize these components using the built-in controls, copy the markup, and adjust the design with **Tailwind CSS**.
By the end of the tutorial, you'll have a fully functional page that is both customizable and responsive.

To create a page, you can install the DDS unplugin, configure it according to your framework and start using the markup
provided in Storybook.

**Make sure to check the markup you copied for icons (usually starting with `<icon-`) and import them according to the Unplugin documentation.**

To find all icons used in a component, please click on the "Used icons from DDS" panel, next to the Design,
Accessibility, HTML and controls. The "Used icons from DDS" panel provides a code snippet with all imports ready to
use in your JavaScript/TypeScript code.

## Selecting and Configuring Components in Storybook

Within this Storybook instance, you'll find a variety of pre-built UI components that you can use to assemble your page.
Here's how to make the most out of them:

### Step 1: Choose a Component
- Browse through the **components** listed in the sidebar. Each component (such as buttons, forms, cards, etc.) can be customized using the controls provided.
- Click on the component you’d like to use for your page. This will display the component’s options and interactive controls.
- It is important to know that many components can be modified and adapted. For example, a two-column accordion is not its own component, but rather a variant of the accordion itself.

### Step 2: Customize the Component Using Controls
- **Controls** appear on the right side of the Storybook interface, allowing you to tweak the component's properties
dynamically. This includes options like:
  - **Text**: Change the text on buttons or headings.
  - **Color**: Customize the background, text, and border colors.
  - **Size**: Adjust the size of elements like buttons, cards, or icons.
  - **State**: Toggle different states such as hover, focus, or active states for interactive components.
- Adjust these controls until the component matches your desired look and behavior.

### Step 3: Copy the Markup or Code
- Once you've customized the component to your liking, you can **copy the generated markup**.
  - Storybook will display the code in the **HTML** panel.
  - Copy this code to your project to use the component as part of your page layout, components, or similar.

### Step 4: Copy and paste the icons import code
- Once you created your component, you need to import all necessary icons.
  - Go to the "Used icons from DDS" panel in Storybook
  - Copy the `import` statements
  - Paste them in your JavaScript/TypeScript code
- If you're using a single entry file, such as `app.js`, `index.js`, `main.js` or similar (usually the case when no
  frontend framework is used) where you put all icon imports, make sure to import every icon only once. If you're using
  different component files, your build tool will most likely take care of tree-shaking any duplicate imports.

## 3. Building Your Page with Storybook Components

After selecting and customizing your components, it's time to assemble them into a page. You can copy the component code
from Storybook and structure it within your HTML layout.

For example, if you want to create a page with a **Button** and a **Teaser**:

1. **Start with a basic layout**
   Set up a simple HTML structure:
   ```html
   <html lang="de">
   <head>
       <meta charset="UTF-8">
       <meta name="viewport" content="width=device-width, initial-scale=1.0">
       <title>My Page</title>
   </head>
   <body>
       <!-- Insert components here -->
   </body>
   </html>
   ```

2. **Add a Button component**
   After customizing the button in Storybook, copy the HTM code for the button and paste it into your HTML file:
   ```html
   <button class="button">Click Me</button>
   ```

3. **Add a Teaser component**
   Similarly, select and customize a **Teaser** component. Once satisfied, copy the markup and add it to your page.

Once you’ve pasted the components, your page will start taking shape. You can use Tailwind to customize the layout and
appearance further.
